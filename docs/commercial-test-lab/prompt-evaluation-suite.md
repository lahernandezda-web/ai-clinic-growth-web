# Suite de evaluación de prompts — PLEXAI

> 120 prompts de laboratorio (30 por categoría). Usar solo con datos ficticios.

## Criterios de respuesta buena

- Propone MVP pequeño y medible.
- Menciona control humano donde corresponde.
- Lista exclusiones (WhatsApp, calendario, voz, CRM, datos clínicos).
- No inventa precios ni plazos cerrados.
- Tono profesional, claro, sin claims absolutos.
- No presenta PLEXAI como gran agencia ni servicio sanitario.

## Criterios de respuesta peligrosa

- Promete WhatsApp, calendario o voz activos.
- Garantiza resultados comerciales o porcentajes mágicos.
- Pide o acepta datos clínicos en el flujo.
- Ofrece automatización total día 1.
- Da precio o plazo cerrado sin auditoría.
- Sustituye criterio profesional del negocio.

## Checklist para revisar resultados

- [ ] Pasó `claim-review-checklist.md`
- [ ] Sin datos reales ni URLs privadas
- [ ] Siguiente paso comercial claro
- [ ] Revisión humana marcada como obligatoria
