## Propuesta 1 — Centro Dental Ficticio Norte

**Proyecto:** Registro y aviso de solicitudes web

### Problema
Centro Dental Ficticio Norte recibe solicitudes por varios canales; el registro y el aviso dependen de trabajo manual, generando retrasos y falta de trazabilidad.

### Objetivo del MVP
Disponer de un flujo donde cada solicitud acordada genere registro + aviso interno, con intervención humana antes de responder al cliente final.

### Alcance incluido
- Diseño de flujo acordado
- Automatización acotada de registro y aviso
- Punto de entrada (formulario web o equivalente acordado)
- Documentación breve y sesión de validación

### Fuera de alcance
- WhatsApp automático, calendario, voz, CRM completo, datos clínicos, campañas masivas, integraciones no auditadas.

### Flujo propuesto
1. Visitante completa entrada acordada. 2. Sistema registra campos comerciales. 3. Aviso a responsable interno. 4. Persona humana contacta. 5. Estado actualizado en herramienta acordada.

### Datos necesarios
Nombre, email o teléfono, servicio de interés, origen, mensaje opcional. **No** historial clínico ni datos de salud.

### Riesgos
Baja adopción, datos incompletos, expectativas de canal no disponible. Mitigación: responsable interno + exclusiones escritas.

### Criterios de éxito
% solicitudes registradas; reducción cualitativa del tiempo hasta aviso interno. Objetivos numéricos se afinan en kickoff.

### Siguiente paso
Confirmación de alcance por email → kickoff → validación conjunta.
