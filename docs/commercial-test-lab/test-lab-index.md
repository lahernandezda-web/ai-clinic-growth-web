## Flujo recomendado de práctica

1. Elegir lead → scoring → decisión.
2. Si auditoría: caso Axx → informe ejemplo → propuesta MVP.
3. Si objeción: roleplay → verificar contra quality system.
4. Si prompt nuevo: suite de evaluación → matriz QA.
