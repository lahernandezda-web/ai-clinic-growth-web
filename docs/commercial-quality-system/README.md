# Sistema de calidad comercial — PLEXAI

## Qué es

Capa de **control de calidad** sobre el material comercial ya existente:

- `docs/commercial-sector-playbooks/` — sector y prospección  
- `docs/commercial-sales-system/` — venta y operación  
- `docs/commercial-quality-system/` — **este pack** (reglas, tono, frases, revisión)

Evita promesas fuera del MVP, lenguaje clínico indebido, claims de empresa grande y automatización total.

| Momento | Documento |
|---------|-----------|
