## Frases aprobadas (referencia rápida)

- Analizamos procesos, detectamos tareas repetitivas y automatizamos con IA solo donde aporta valor.  
- Empezamos por un MVP medible con control humano.  
- El flujo demostrable hoy: solicitud web → registro → aviso interno → seguimiento acordado.  
- WhatsApp / calendario / voz: se pueden valorar en fase posterior, no activos en este piloto.  
- No gestionamos datos clínicos ni de pacientes.  
- Propuesta económica tras definir alcance y métrica.
