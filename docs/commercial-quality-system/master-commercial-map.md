## Qué revisar antes de enviar algo a un cliente

**Checklist mínimo (5 min):**

1. `claim-review-checklist.md` — completo  
2. Buscar frase en `forbidden-and-approved-phrases.md`  
3. Confirmar exclusiones si es propuesta (`mvp-proposal-template.md`)  
4. Sin datos clínicos / pacientes / sensibles  
5. Sin precio cerrado salvo propuesta formal acordada  
6. Siguiente paso concreto en el email  

**Documentos por tipo de envío:**

| Envío | Revisar |
|-------|---------|
| Email frío | tone-guide + forbidden phrases + prospecting |
| Informe auditoría | audit-report-template + checklist |
| Propuesta MVP | mvp-proposal-template + offer-packaging + checklist |
| Mensaje WhatsApp manual | forbidden #4–7, #73; no prometer bot |
| Contrato (humano) | fuera de este pack — asesoría legal |
