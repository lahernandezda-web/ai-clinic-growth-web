# Sistema comercial-operativo PLEXAI

## Qué es este sistema

Este directorio contiene la **documentación interna de venta y operación comercial** de PLEXAI: cómo cualificar leads, ejecutar auditorías gratuitas, redactar informes, preparar propuestas MVP, conducir llamadas, hacer seguimiento, incorporar clientes y controlar alcance.

El mensaje central que debe permear todo el uso de estos documentos es:

> *Analizamos los procesos de tu negocio, detectamos tareas repetitivas y diseñamos automatizaciones con IA solo donde realmente aportan valor.*

No es un CRM, no es software y **no sustituye** contrato firmado, propuesta económica con importes cerrados ni asesoría legal o fiscal.

## Flujo comercial recomendado

```
Contacto → Cualificación → [Descartar | Nutrir | Auditoría | Demo | Propuesta MVP]
                ↓
         Auditoría gratuita (30–60 min)
                ↓
         Informe + 1–3 automatizaciones priorizadas
                ↓
         Propuesta MVP acotada
                ↓
         Onboarding + Kickoff + Entrega por fases
```

Cada transición debe tener **siguiente paso concreto** (fecha, responsable, entregable), no “ya te escribo”.

## Límites comerciales obligatorios

Al usar este sistema, **nunca** prometas lo que el producto o el MVP actual no demuestran:

| No prometer | Por qué |
|-------------|---------|
| WhatsApp activo en el flujo comercial | No implementado como canal automatizado en el MVP |
| Calendario / agenda integrada | No implementado |
| Voz / telefonía con IA | Fuera de alcance del MVP |
| CRM completo o gestión de pacientes | Solo captura y seguimiento comercial ordenado |
| Automatización total del negocio | Enfoque por proceso, con control humano |
| Integraciones no validadas | Cada integración requiere diagnóstico y fase 2 |
| Sustituir personal clínico o sanitario | PLEXAI no es servicio médico ni sanitario |
| Tratamiento de datos clínicos o de pacientes | Fuera de alcance y de cumplimiento del formulario actual |
| Precios o plazos cerrados sin alcance | Van en propuesta formal, no en chat informal |
| PLEXAI como agencia líder, multinacional o equipo grande | Posicionamiento honesto: B2B, MVP, criterio |

**Sí puedes prometer (con demo o entregable verificable):**

- Auditoría gratuita de procesos (vía formulario web o reunión estructurada).
- Diseño de automatizaciones pequeñas con supervisión humana.
- Flujo demostrable cuando exista en el MVP: solicitud web → registro → aviso interno → seguimiento en hoja o herramienta acordada.

## Filosofía comercial PLEXAI

- **B2B** orientado a negocios con procesos repetitivos (clínicas, academias, servicios locales, etc.).
- **MVP primero:** una automatización útil y medible antes que un “sistema completo”.
- **Automatización con criterio:** si no aporta valor o no hay proceso claro, no se vende.
- **Control humano:** la IA asiste; no decide sola en temas sensibles ni sustituye criterio del negocio.
- **Empezar pequeño, medir, escalar:** métricas antes/después, no promesas absolutas.
- **Sin humo:** no inventar casos de éxito ni integraciones activas.

## Naturaleza del documento

- **Uso interno** para quien comercializa y entrega proyectos PLEXAI.
- **No modifica** las páginas legales (`/aviso-legal`, `/privacidad`) ni compromisos contractuales existentes.
- Ante duda sobre datos personales, sectores regulados o alcance legal, **detener la venta** y escalar a asesoría profesional antes de ampliar el proyecto.
